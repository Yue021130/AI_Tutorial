# 06 · 相关工作：MAE 在 MIM 家族中的位置

MAE 不是孤立的：BEiT 先证明了"掩码+预测"在视觉可行，MAE 把它简化并提速，随后 SimMIM / MaskFeat / CAE / VideoMAE 各自沿不同轴推进。比较它们的关键是三个设计轴：**预测目标的空间**（离散 token / 像素 / 特征 / 潜变量）、**掩码策略与比例**、**decoder 容量**。

## 1. 总对比表

| 方法 | 目标（损失） | 掩码策略 | tokenizer | decoder | 关键洞察 |
| --- | --- | --- | --- | --- | --- |
| **BEiT** (2021.6, arXiv:2106.08254) | dVAE 离散 token，交叉熵 | 40%，block 式 | **需要**（先训 dVAE） | 浅（待核验） | 语义目标可行；两阶段 |
| **MAE** (2021.11, arXiv:2111.06377) | 归一化像素，MSE，仅 masked | **75%，random** | 无 | 轻量（512×8） | 非对称 encoder + 高掩码 → 可扩展 |
| **SimMIM** (2021.12, arXiv:2111.09886) | 原始像素，L1 | ~60%，random（ViT-B 口径） | 无 | **极浅预测头** | 简单回归即可，无需归一化/tokenizer |
| **MaskFeat** (2021.12, arXiv:2112.09133) | **HOG 特征**回归 | 中低比例（待核验） | 无（手工特征） | 无/极浅 | 免生成式 decoder，低层特征目标即有效 |
| **CAE** (2022.2, arXiv:2202.03026) | 潜空间对齐 + 重构 | ~60%（待核验） | 无 | 较深 | encoder 表征与"补全任务"显式解耦 |
| **VideoMAE** (2022.3, arXiv:2203.12602) | 像素 MSE | **90–95%，tube 掩码** | 无 | 轻量 | 时间维冗余更高 → 掩码更高 |

> 各方法 ImageNet 微调 top-1 大致都在 83–85（ViT-B/L 口径）：MAE ViT-B 83.6、BEiT ViT-B 83.2 相对可靠；SimMIM ViT-B ≈84.0、MaskFeat ViT-L ≈84+、CAE ViT-B ≈83.6 均待核验，以各自论文为准。差异更多在**训练成本与管线复杂度**，而非饱和精度。

## 2. 逐个分析（相对 MAE 的差异）

### 2.1 BEiT：语义目标的先驱
- **做法**：先训一个 dVAE 把图像 patch 量化为离散视觉词表，再让模型预测被掩 patch 的 token ID（交叉熵）。
- **相对 MAE 的得失**：离散 token 目标更"语义"，linear probe 更强；但 dVAE 需要单独预训练（两阶段），目标质量受 tokenizer 上限制约，且当时用的 block 掩码 + encoder 看全部 token → 训练慢（MAE 报告的数倍加速即以此为参照，具体倍数待核验）。
- **历史定位**：证明了 MIM 路线可行；MAE 证明了"不需要语义目标也能行"。

### 2.2 SimMIM：极简主义
- **做法**：直接回归**原始像素**（L1），decoder 用极浅的预测头（一两层量级，具体待核验），掩码 ~60%。
- **相对 MAE 的差异**：不再逐 patch 归一化、decoder 更浅——说明 MAE 的归一化与 decoder 容量都不是硬门槛；真正不可省的是"掩码 + 回归补全"这一骨架本身。
- **启示**：MAE 论文里"归一化像素略优于原始像素"的增益是锦上添花，不是命门。

### 2.3 MaskFeat：换目标不换骨架
- **做法**：预测被掩区域的 **HOG 特征**（手工设计的梯度方向直方图），基本不设 decoder。
- **相对 MAE 的差异**：目标从生成像素换成判别性特征——回避"生成式 decoder 是否在浪费时间"的质疑；HOG 免训练、免 tokenizer。
- **启示**：目标空间的"层级"可调，像素与语义 token 之间存在实用的中间点。

### 2.4 CAE：把解耦做到形式上
- **做法**：encoder 只编码可见 patch；被掩 patch 经"潜空间回归"直接对齐到 encoder 的潜空间（即在表征空间补全），再由 decoder 解码回像素约束。
- **相对 MAE 的差异**：显式约束"补全发生在潜空间"，使下游推理只依赖 encoder、表征与像素重构解耦更彻底，linear probe 更强（待核验具体数值）。
- **启示**：呼应 MAE 消融里"decoder 深度补偿 linear probe"的现象——在潜空间补全等于把抽象从 decoder 搬回 encoder。

### 2.5 VideoMAE：换模态，掩码更狠
- **做法**：视频版 MAE；因相邻帧高度相似（**因果时间冗余**），随机掩码会被"抄相邻帧"作弊，故用 **tube masking**（同一空间位置跨时间整条掩掉）+ 比例提到 **90–95%**。
- **相对 MAE 的差异**：证明"最优掩码率是数据冗余度的函数"这一论断——图像 75%、视频 90+%；小 decoder 在更高掩码率下依然够用。
- **启示**：MIM 迁移到新模态时，**先分析该模态的冗余结构**，再定掩码策略与比例。

## 3. 统一视角：MIM 的三轴设计空间

```
目标空间:   离散 token (BEiT) ←→ 像素 (MAE/SimMIM) ←→ 手工特征 (MaskFeat) ←→ 潜变量 (CAE, JEPA 方向)
掩码策略:   random (MAE) / block (BEiT) / tube (VideoMAE) ；比例 = f(数据冗余度)
decoder:    重 Transformer (早期) → 轻量 (MAE) → 极浅 (SimMIM) → 无 (MaskFeat) → 潜空间 (CAE)
```

MAE 的历史贡献是**把三轴同时推向"简单"的一端并保持精度**，从而成为可扩展的基线；后续工作沿各轴细化。更远处的 JEPA 路线（预测潜空间而非像素）可视为"目标空间轴"的外推——见 `07-open-questions.md`。

## 4. 时间线

```
2021.06  BEiT     掩码+离散token目标，MIM 起跑
2021.11  MAE      非对称结构 + 75% 随机掩码 + 像素回归，规模化
2021.12  SimMIM   极简回归；MaskFeat  HOG 特征目标
2022.02  CAE      潜空间对齐
2022.03  VideoMAE 视频 + tube masking + 90%+
```
