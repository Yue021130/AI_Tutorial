# 01 · 动机：从 AE / DAE / MLM 到 MAE

MAE 不是凭空出现的。它的每个设计决定都能在自监督学习的历史里找到对应物。本章沿「自动编码器 → 去噪自动编码器 → BERT 的掩码语言建模 → MAE」这条线，回答两个问题：**视觉自监督为什么长期落后于 NLP？MAE 靠哪两个判断追上来？**

## 1. 自监督学习的三大范式

| 范式 | 代表 | 核心思想 | 学到什么 |
| --- | --- | --- | --- |
| 生成式（generative） | AE、VAE、自回归模型 | 重建输入本身，建模 $p(x)$ | 数据分布的结构 |
| 对比式（contrastive） | SimCLR、MoCo v1-v3 | 拉近同一样本的两个增广、推远不同样本 | 实例级判别性特征 |
| 掩码预测（masked modeling） | BERT、BEiT、MAE | 遮住输入的一部分，预测被遮住的内容 | 对缺失信息的推理能力 |

MAE 属于第三条线，但它同时借用了第一条线的"编码器-解码器"骨架，并针对视觉信号的性质做了两处关键改造（见 §5）。

## 2. AE → DAE：去噪思想的起源

**自动编码器（AE）**：编码器把输入压到低维潜在码，解码器再重建输入。潜在码被期望是好的表征。历史上 AE 的两个问题：

1. **重建 ≠ 有用**。解码器容量够大时，潜在码只需保留低层信息即可完成重建，学不到语义抽象。
2. **捷径（shortcut）**。在 CNN 时代，"卷积 + 上采样"式解码器可以从邻域像素插值恢复大部分内容，信息绕过编码器直接从输入流向输出，掩码/腐蚀形同虚设。

**去噪自动编码器（DAE，Vincent et al., 2008）**：对输入加噪/腐蚀，要求从损坏版本重建干净版本。核心洞察：**好的表征是能从损坏观察中恢复信号的表征**——腐蚀把"捷径"堵死了一部分。MAE 是 DAE 的直系后代：**随机掩码就是一种结构化的腐蚀方式**。

但在 CNN 时代 DAE 路线没有成为主流：掩码后的卷积运算需要专门的 MaskedConv 处理；同时对比学习（MoCo / SimCLR）更简单有效，占据了主导。

## 3. NLP 的启示：MLM 为什么成功

BERT 的掩码语言建模（masked language modeling, MLM）：随机遮住 15% 的 token，用双向 Transformer 预测被遮 token 的离散 ID，交叉熵损失。成功依赖两个语言性质：

1. **token 是低冗余、高语义密度的离散单元**。一个被遮住的实词很难从邻词线性外推，预测它需要句法与语义理解——每个被遮 token 都是有信息量的监督信号。
2. **输出空间是有限词表**，交叉熵有明确目标，无需定义连续回归目标。

对比之下，**图像的统计性质几乎相反**：

- **空间冗余度高**。自然图像局部平滑、纹理重复，相邻 patch 高度相关——单个 patch 的内容大都可以由邻域外推。
- **信息密度低且不均匀**。大量 patch（天空、墙面、皮毛）携带极少语义；少数 patch（眼睛、轮廓）携带几乎全部语义。
- **输出是连续高维像素**，没有现成的"词表"（除非额外训练 tokenizer，见 BEiT）。

因此，把 MLM 的 15% 掩码率直接搬到图像上，"填空"任务过于容易：模型靠局部插值即可完成，学不到整体理解。**冗余性本身成了任务设计的敌人。**

## 4. ViT 改变了什么

ViT（Dosovitskiy et al., 2020）把图像切成 patch 序列喂给标准 Transformer，这一步对掩码建模是决定性的：

1. **结构同构**：图像 patch ≈ 语言 token，BERT 式"遮 token、预测 token"的框架天然适配。
2. **绕开 MaskedConv**：直接丢掉 token 即可实现掩码，无需特殊卷积算子。
3. **捷径被削弱**：Transformer 解码器没有卷积的局部归纳偏置，无法靠"逐像素复制邻域"轻松作弊。

但直接照搬 BERT 仍有两个未解问题：输出目标怎么定（连续像素回归？离散 token？）；掩码率该是多少。这正是 BEiT（先训 dVAE tokenizer，再预测离散 token）与 MAE（直接回归像素 + 高掩码率）的分岔点。

## 5. MAE 的两个关键判断

### 5.1 信息冗余 → 高掩码率是特性而非 bug

既然图像冗余，那就**掩得足够狠**，让"填空"无法靠局部外推完成。掩码率 75% 时，可见的 patch 稀疏地散布全图，恢复任何一个被掩 patch 都需要跨区域的整体推理（物体的形状、部件间的拓扑关系）。

75% 同时带来第二个好处：**encoder 只需处理 25% 的 patch**，计算量大幅下降——冗余性从"任务的敌人"变成了"效率的来源"。

### 5.2 可扩展性 → 非对称 encoder-decoder

如果把 mask token 一起喂给 encoder（BERT 的做法），序列长度不变，掩码率再高也**不省计算**，训练 ViT-L / ViT-H 的成本不可接受。MAE 的非对称设计：

- **encoder**：标准 ViT，只处理 25% 可见 patch → token 数 196 → 49，计算量约为全量的 1/4 量级；
- **decoder**：轻量（小宽度、浅深度），处理全部 196 个 token（可见 patch 的编码 + mask token）完成重构，且**只在预训练阶段存在，下游直接丢弃**——所以可以做得任意小而不心疼。

再加上**目标用逐 patch 归一化的像素 + MSE**：无需预训练 tokenizer（BEiT 需要先训 dVAE，两阶段、引入额外偏差），整个流程单阶段、无特殊增广、无对比学习的负样本工程。**简单性本身就是可扩展性的一部分**：数据越大模型越大，像素目标不会成为瓶颈。

## 6. 与对比学习的互补

| 维度 | 对比学习（MoCo v3 等） | MAE |
| --- | --- | --- |
| linear probe | 强（特征线性可分性好） | 相对弱（论文中显著低于对比方法，具体数值待核验） |
| fine-tune 后分类 | 强 | 更强 |
| 检测 / 分割等密集任务 | 增益有限 | 增益显著 |
| 依赖 | 强增广、大 batch、（历史上）负样本 / EMA | 弱增广（crop + flip）、无 EMA、掩码即增广 |
| 训练稳定性 | 对 batch / lr 敏感 | 简单稳定 |

直觉：对比学习优化特征空间的**区分度**；MAE 优化对图像**内容的理解**。后者更贴近检测/分割需要的密集、结构化语义，这解释了 MAE 在下游密集任务上的优势。

## 7. 小结

一句话概括 MAE 的构造逻辑：

> MAE = DAE 的去噪思想 + ViT 的序列化架构 +（视觉冗余 ⇒ 掩码率 15% → 75%）+（encoder 只算 visible ⇒ 非对称结构 ⇒ 可扩展）+（像素 MSE ⇒ 免 tokenizer ⇒ 简单）。
