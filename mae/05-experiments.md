# 05 · 实验与调参

本章面向"真的要自己训一个 MAE"的场景：超参基线、每个维度怎么动、要多少算力、失败模式长什么样。论文级数值以官方仓库为准，不确定处标注「待核验」。

## 1. 超参基线（ImageNet-1k，ViT-L 口径）

| 维度 | 推荐起点 | 说明 |
| --- | --- | --- |
| mask ratio | **0.75** | 最强单一杠杆之一，先扫它 |
| patch / 输入 | 16 / 224 | N=196，可见 49 |
| encoder | ViT-B(768/12) → ViT-L(1024/24) | 先 B 后 L |
| decoder | dim 256–512, depth 1–8 | 见 §2.2：取决于你要 ft 还是 probe |
| 优化器 | AdamW, base lr **1.5e-4 × bs/256**, wd **0.05** | betas (0.9, 0.95)（ViT-L/H，待核验） |
| batch size | 尽量大（512–4096），lr 同步缩放 | 256 也能训，精度略损 |
| epochs | 原型 300 → 认真 800 → 对齐论文 1600 | epoch 数是精度第二强杠杆 |
| warmup / 调度 | 数十 epoch warmup + cosine（待核验） | 长调度必须有 warmup |
| 增广 | RandomResizedCrop + flip，**无 color jitter** | 加了大概率变差 |
| 精度 | bf16 混合精度 | fp16 注意 loss scale |

## 2. 逐维度调参指南

### 2.1 mask ratio
- 扫描网格：{0.5, 0.6, 0.7, 0.75, 0.8, 0.85, 0.9}。
- 规律：fine-tune 曲线在 40–80% 宽平、75 附近最优；linear probe 峰值约 75% 且更尖锐；≥0.9 明显崩（信息不足）。
- 数据/分辨率更高时最优值上移（VideoMAE 在视频上 0.9+）；小数据/小模型可略降到 0.6–0.7。

### 2.2 decoder 容量
- 目标是 **fine-tune 精度** → depth 1–4、dim 256 足够，省下的算力全喂 encoder。
- 想要好看的 **linear probe** → depth 8、dim 512。
- decoder 过大只增加预训练成本，不随 encoder 迁移——典型的"花冤枉算力"。

### 2.3 学习率 / weight decay
- lr 过高：attention 输出溢出 → loss 变 NaN（bf16 更耐造，但不是免死金牌）；出现 NaN 先降 lr 到 1/2 再排查。
- lr 过低：收敛慢且最终精度差；掩码任务的 loss 曲线平缓，容易误判为"收敛了"。
- wd 0.05 为默认；长调度（≥1600 ep）可试 0.1；wd 过小会过拟合"重建像素"本身而非学表征。

### 2.4 batch / epoch 的预算分配
- 固定总算力时，**优先加 epoch 而非加 batch**（精度来源更稳）；batch 大了记得 lr 线性缩放。
- 300 ep 只够验证管线正确性；800 ep 与 1600 ep 之间通常还有可观提升（待核验具体曲线）。

### 2.5 微调（MAE 兑现性能的关键步骤）
- MAE 不微调基本不可用（linear probe 弱是已知现象），**评估必须以 fine-tune 为主**。
- 要点：分层 lr decay（浅层乘 0.65–0.75 逐层递减，待核验）、drop path 0.1–0.2、100 ep 量级、224 → 逐渐放大分辨率（如最终 512）。
- 微调超参不当会把预训练优势全部吃掉——排查微调配方前不要怪预训练。

## 3. 算力估计（粗略量级，供规划）

| 配置 | 估计 | 备注 |
| --- | --- | --- |
| 冒烟/教学（本目录小模型） | CPU 分钟级 | `python code/mae_minimal.py` |
| ViT-T/B + IN-100 或子集 + 200–300 ep | 单卡（如 A100/3090）1–2 天 | 原型验证 |
| ViT-B + IN-1k + 800 ep | 8 卡 1–2 天 | 待核验 |
| ViT-L + IN-1k + 1600 ep | 8×A100 量级约 1–2 周 | 待核验；对齐论文需大 batch |
| 效率来源 | encoder 只算 25% token | 墙钟加速约 3×（论文口径，待核验） |

结论：**MAE 是少数单机可完整复现思想、多机可对齐论文的预训练方法**。建议路线：小数据 + 小模型验证管线 → IN-1k + ViT-B 复现量级 → 视需要上 ViT-L。

## 4. 常见失败模式（按隐蔽程度排序）

1. **mask 语义弄反**（0/1 颠倒）：不报错、loss 异常低且几乎不降——模型在重建可见 patch（恒等任务）。检查 `(loss * mask).sum() / mask.sum()` 的 mask 定义。
2. **mask token 没加位置编码**：loss 能降但重构图"糊成一片"，模型无法定位该填哪里。
3. **`ids_restore` 误用 `ids_shuffle`**：decoder 的可见/掩码位置与原图错位，loss 波动大且重构混乱。
4. **顺序契约破坏**：patchify、Conv2d 展平、位置编码网格三者顺序不一致（见 04 §2.1）——症状同上。
5. **mask ratio 太低（≤0.5）**：训练正常，fine-tune 增益微弱——任务被局部冗余捷径解决，白训。
6. **lr 过高 → NaN**：先降 lr / 换 bf16 / 检查 loss scale。
7. **color jitter 等强增广**：预训练 loss 更低但下游更差——掩码已是增广，外置增广摊薄信号。
8. **decoder 太大**：训练慢、精度不变——容量没花在 encoder 上。
9. **微调没做分层 lr decay / drop path**：预训练增益被吞，误以为 MAE 无效。
10. **用 linear probe 当唯一指标**：得出"MAE 不行"的错误结论——这是设计使然，不是 bug。

## 5. 评估协议

1. **重构可视化**：`unpatchify` 还原整图，叠加 mask；注意 pred 在归一化像素空间，可视化时反归一化或只看结构。训练早期应看到"轮廓级"补全而非逐像素复制。
2. **linear probe**：作参考指标，预期偏低属正常。
3. **fine-tune（主指标）**：IN-1k top-1；小算力可用 IN-100/k-NN 做快速代理。
4. **下游密集任务**：COCO / ADE20K 才是 MAE 与对比学习拉开差距的地方。
5. **消融纪律**：一次只动一个维度；每个 run 换 seed 至少 2 次再下结论。

## 6. 一条可执行的复现路线

```
第 1 周  跑通 code/mae_minimal.py 冒烟测试；IN-100 + ViT-T + 200ep 验证管线
第 2-3 周 IN-1k + ViT-B + 300ep 基线；扫 mask ratio {0.6,0.75,0.9}
第 4 周+ 加 epoch 到 800；加分层 lr decay 的微调；对照监督 ViT-B 基线
```

指标锚点（IN-1k fine-tune，供 sanity check）：ViT-B ≈ 83.6（MAE 论文值）；自己的复现低 1–2 个点通常来自 epoch/batch 不足。
