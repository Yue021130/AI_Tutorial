# 07 · 开放问题与待验证假设

MAE 表面上"调通了"，但**为什么**这样设计恰好有效，远未有定论。本章分两部分：开放问题（当前没有公认答案）与待验证假设（可以设计实验检验的猜想）。

## 1. 开放问题

### Q1 最优掩码率的理论刻画
经验事实：图像 75%、视频 90%+、语言 15%。直觉解释是"掩码率 ≈ 数据冗余度的函数"，但没有公认的量化理论。能否从信息论（如 patch 间的条件熵）或率失真角度**先验地**预测 $\rho^*$？若能，MIM 迁移到新模态（点云、音频、多模态）就不必重新网格搜索。

### Q2 MAE 学到的表征层级：语义还是纹理统计
像素重构的监督信号偏底层，但 fine-tune 后语义任务很强。两种解释：(a) 高掩码率下"重构必须理解语义"（任务难度反推抽象层级）；(b) 重构只学到良好的中间特征，语义来自微调。linear probe 弱、fine-tune 强的现象支持 (b) 的成分不小。表征空间的几何（各层各向异性、特征聚类结构）尚缺系统刻画。

### Q3 "预测什么"决定抽象层级
像素（MAE）→ 手工特征（MaskFeat）→ 离散语义 token（BEiT）→ 潜变量（CAE / JEPA 路线）。这是同一骨架在目标空间轴上的展开。核心争论：**抽象层级越高是否必然上限越高**？还是只要任务难度（掩码率）配平，层级无关紧要？后者若成立，JEPA 式"放弃像素"的收益就要重新解释。

### Q4 掩码预测作为通用预训练原语
掩码（离散缺失）与加噪（连续退化）分别是 BERT/MAE 与 diffusion 的 corruption 算子。两者是否是同一"补全式预训练"原理的特例？MAE 单步预测 vs diffusion 多步迭代，收敛到的表征有何本质差异？（交叉证据：两者微调后下游表现均强。）

### Q5 scaling 行为
监督学习与对比学习各有 scaling law。MIM 的精度–参数–数据–计算关系是否一致？具体子问题：数据集扩大（IN-21k → 网络级数据）时最优掩码率是否上移？epoch 需求是否随数据增长而下降？

### Q6 mask token 的计算角色
一个共享向量 + 位置编码携带"哪里缺、缺什么位置"的全部信息。decoder 内部对 mask token 做了什么计算——把它当作"查询向量"在聚合可见信息，还是惰性占位？中间层可视化（attention 从 mask token 指向哪些可见 patch）能提供证据。

### Q7 非对称结构的极限
MAE 消融显示 fine-tune 场景 decoder 可浅至 1 层、mask token 近乎可省；SimMIM 进一步极简化。极限问题：**decoder 能否为零层**（直接从 encoder 输出回归）而不损失迁移性能？这条边界直接决定"预训练开销的下界"。

### Q8 预训练–微调的输入分布一致性
MAE encoder 预训练时永远只见"稀疏可见"的输入，微调时见完整图像——与 BERT 的 `[`mask`]` 错配方向相反但都存在。这一差异对微调动力学（哪些层变化最大）有何影响？

## 2. 待验证假设（附实验设计）

以下假设都可以在小算力上检验（IN-100 / IN-1k 子集 + ViT-T/B + 200–300 ep），控制变量后比较 fine-tune 精度。

### H1 数据规模越大，最优掩码率越高
- **设计**：IN-1k 的 10% / 50% / 100% 三档数据 × $\rho \in \{0.6, 0.75, 0.9\}$ 网格，固定 epoch 与算力配平策略。
- **判据**：$\rho^*$ 随数据规模单调上移则成立。
- **意义**：为 Q1 提供经验曲线；指导大模型预训练的掩码率选择。

### H2 逐 patch 归一化的增益主要来自剔除低频/光照分量
- **设计**：重构目标分别取 raw 像素 / 逐 patch 归一化 / 高频残差（减去低通版本）/ 仅亮度通道归一化。
- **判据**：高频残差 ≈ 归一化 ≫ raw，且亮度归一化占主要份额则成立。
- **意义**：把"归一化像素"从 trick 上升为"目标该在什么频段"的原则，指导新目标设计（连接 MaskFeat 的 HOG 选择）。

### H3 decoder 深度补偿的是"目标抽象层级"而非"重构精度"
- **设计**：训练不同 decoder 深度（1/4/8 层）至**重构 loss 匹配**（浅 decoder 多训若干 epoch），再比 linear probe。
- **判据**：loss 匹配后浅 decoder 的 linear probe 仍显著更低，说明深度贡献在抽象而非拟合。
- **意义**：直接检验 02 §4.2 的解释，连接 CAE 的潜空间对齐动机。

### H4 高掩码率隐式提供课程学习效应
- **设计**：固定 $\rho = 0.75$ vs 课程 $\rho: 0.5 \to 0.9$（线性爬升）vs 逆课程 $0.9 \to 0.5$，比较同 epoch 下的收敛速度与最终精度。
- **判据**：正课程加速收敛且最终精度不降、逆课程变差则成立。
- **意义**：若成立，掩码率不只是超参而是可调度量；后续可做自适应掩码（按重构误差动态调整 $\rho$）。

### H5 MAE 与对比学习的特征互补
- **设计**：同结构 ViT-B 分别训 MAE 与 MoCo v3（或用现成权重），特征 concat 后做 linear probe / k-NN，对照各自单独。
- **判据**：concat 显著超过两者 max 则成立。
- **意义**：量化"理解型"与"判别型"表征的正交性，为混合预训练目标提供依据。

## 3. 建议的动手顺序

1. 先做 H2、H3（改动只在目标/decoder，单卡可完成）；
2. 有 8 卡资源后做 H1（掩码率×数据规模网格）；
3. H4、H5 作为进阶；每完成一个，把结论回写到 `05-experiments.md` 对应小节。
